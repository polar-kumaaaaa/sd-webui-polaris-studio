# Polaris Studio（ポラスタ）

Stable Diffusion WebUI reForge 向けの拡張機能です。
画像生成を「プロジェクト → シーン → カット案」の単位で整理し、プロンプトの組み立て、試し生成、まとめての生成、できた画像の選別までを 1 つの画面で行えます。

*A reForge extension that organizes image generation into projects, scenes and cuts, with a tag-based prompt editor, generation queues, an image browser and "Books" exported as metadata-free ZIPs. The UI is in Japanese.*

## 動作環境

- [Stable Diffusion WebUI reForge](https://github.com/Panchovix/stable-diffusion-webui-reForge) で動作を確認しています。
- 追加のライブラリは不要です（WebUI に入っているものだけを使います）。

## インストール

1. WebUI の「Extensions」→「Install from URL」を開きます。
2. 「URL for extension's git repository」に次を入れて「Install」を押します。
   ```
   https://github.com/polar-kumaaaaa/sd-webui-polaris-studio.git
   ```
3. WebUI を再起動します。

画面上部の設定の行の右端に「Polaris Studio」ボタンが出ます。押すか **Alt+P** で開きます（もう一度 Alt+P で元の画面に戻ります）。

## 見本データ

`samples/projects.json` に、タグ定義・シーン・カット案の入った見本のプロジェクトがあります。
使うときは、WebUI を止めてから拡張フォルダの `data/projects.json` としてコピーし、起動し直してください。

```
extensions/sd-webui-polaris-studio/data/projects.json
```

> すでに `data/projects.json` があるときにコピーすると、今のプロジェクトがすべて置き換わります。
> 見本を読み込んだあとは、新しいプロジェクトを作るときに「タグ定義」で「サンプル からコピー」を選ぶと、見本のタグ定義を引き継げます。

## 主な機能

### プロジェクト・シーン・カット案
- プロジェクトごとに、シーンとカット案（1 枚の絵の案）を並べて管理します。カット案はドラッグで並べ替えられ、シーンをまたいで移動できます。
- シーンは折りたたんで 1 行にできます。
- 画像をシーンにドロップすると、その画像からカット案を作ります。

### プロンプト編集
- タグは「カテゴリ」ごとに登録します。カテゴリには「排他（1 つだけ）」「ネガティブ専用」を指定できます。
- 左のカテゴリから選んだタグを右に並べると、その順でプロンプトが組み立てられます。プロンプト欄は直接書き換えることもできます。
- プロンプト欄で、右の「追加したタグ」のどれにも当たらないタグ（消したつもりで残ったもの・手で書いたもの）には赤い印が付きます。欄の上に「追加したタグにないもの n 個」と出て、マウスを乗せるとその一覧が見られます。
- 保存のたびに履歴を残し、前の状態に戻せます。
- 拡張機能「プロンプト大辞典」（sd-webui-prompt-dictionary）を入れていると、上部に「📖 大辞典」が出ます。押すと大辞典の検索パネルを右に出し、「挿入」で最後にカーソルを置いたプロンプト欄（ポジティブかネガティブ）のカーソル位置にタグを入れます。閉じると、パネルは WebUI の元の場所に戻ります。開いていたかは覚えておき、次に編集画面を開いたときも出します。

### 生成
- カット案ごとに画像のサイズ（幅 × 高さ）を持ちます。プロンプト編集の上部で変えられ、「⇄」で縦長と横長を入れ替えられます。同じプロンプトでも縦長と横長で絵の印象が変わるので、「生成」もキューもカット案のサイズで生成します。
  - サイズを決めていないカット案は、WebUI の幅・高さのまま生成し、最初に生成した画像のサイズを覚えます。
  - 新しいカット案は、同じシーンで最後にサイズを決めたカット案のサイズから始まります。画像をドロップして作ったカット案は、その画像のサイズになります。
- 「生成」で 1 枚だけ試しに生成します。そのあと WebUI の txt2img で生成した画像も、そのカット案に保存されます。txt2img の画面の上に「ポラスタ：プロジェクト / カット案 に保存中」の帯が出ている間が対象で、帯の「解除」を押すと通常の出力先に戻ります。別のカット案で「生成」を押すと、保存先はそのカット案に切り替わります。サムネイル一覧では、生成元「txt2img」で絞り込めます。
- 「キュー」に Steps・Batch・Seed などを決めて登録し、キュー管理からまとめて実行します。
- 進捗は画面右上のトーストに出ます。生成中も画面は操作できます。
- 生成はいつもの txt2img の画面を使います。実行すると、プロンプト・Steps・Seed などが txt2img の欄に書き込まれます。

### ポーズ（OpenPose）
- プロンプト編集の上部の「ポーズ」で、カット案ごとに 1 つのポーズ（OpenPose）を編集できます。ControlNet（WebUI に組み込みのもの）を使います。
- 「画像から取り出す」で、カット案の画像（または読み込んだ画像）から DWPose（dw_openpose_full）でポーズを取り出します。「＋ 人」でひな形の人を足すこともできます。
  - 取り出し元はカット案の画像のサムネイルから選びます。ダブルクリックでそのまま取り出します。ブラウザの外から画像をドロップしても取り出せます。
  - ビューワーの「ポーズを抽出」で、見ている画像からポーズを取り出して、そのカット案のポーズの画面を開きます。
- 体・手（指の関節）・顔の点を 1 つずつドラッグで動かせます。囲んで選んだ点はまとめて動かせます。点をダブルクリックすると、そこから体の外に向けてまとめて選びます（肩なら腕と手、ひじなら手首と手、鼻なら目・耳・顔、首なら手のほかの全部。指の関節なら指先まで、顔の点なら顔全体）。Delete で点を隠し（絵に描かれない）、Shift+Delete で見せます。ホイールで拡大・縮小、右ドラッグで動かして見られます。Ctrl+Z で元に戻せます。
- 2 点以上を選ぶと（Ctrl+A で全部）、比率を保ったまま、まとめて大きく・小さくできます。Alt+ホイールか、「選んでいる点」の「大きさ」のスライダー（25〜200%）・「−5%」「＋5%」で変えます。中心は選んだ点の範囲の真ん中です。
- 手の点か体の手首を選ぶと、その手を手首を中心に動かせます。「反転」（H）で手のひらの表と裏を入れ替え（親指が反対側に移ります）、手首のそばの白い丸（ふだんは腕の側）のドラッグ（Shift で 15° ずつ）か Q・E（15°、Shift で 1°）で回します。
- 取り出し元の画像を薄く下に敷けます。OpenPose の JSON の読み込み・書き出しもできます。
- 「『生成』とキューでこのポーズを使う」にすると、「生成」とキューのときだけ、選んだ ControlNet のユニットを WebUI の設定に関係なくオンにし、プリプロセッサなしでこのポーズの絵を入れます（モデル・重み・開始・終了・重視も、ここで決めた値）。WebUI の ControlNet の画面は変えません。キューは登録したときのポーズを使います。
- 「深度（depth）」の「取り出し元の画像の深度も入れる」にすると、ポーズを取り出したカット案の画像から ControlNet のプリプロセッサ（初期値は depth_anything_v2）で奥行きを作り、別のユニットに入れます。手の形や体の厚み、服や髪の形も元の画像に近づきます。ユニット・プリプロセッサ・モデル・重み（初期値 0.5）・開始・終了を選べます（重視はポーズと同じ）。名前に depth を含む SDXL 用の ControlNet のモデルが必要です。ファイルから読み込んだ画像やドロップした画像から取り出したポーズでは使えません。
  - 取り出したあとに動かした腕・手・脚は、取り出し元の画像の元の位置を背景の色（画像の縁の色）で塗ってから深度を作ります。元の手足が深度に残って、動かした手足と一緒に描かれてしまうのを防ぐためです。塗る場所は、深度を使うときにポーズの絵の上に薄い赤で出ます。取り出したときの点はポーズと一緒に保存します（JSON の書き出しには入りません）。この機能より前に取り出したポーズでは塗らないので、取り出し直してください。
  - 自動で消す範囲は「自動の太さ」（初期値 × 1）で太くできます。足りないところは「🖌 塗る」（B キー）でドラッグして塗り足せます。Shift を押しながら塗ると「消さない範囲」になり、自動の範囲からも外せます。筆の太さはスライダーで変えられ、塗った範囲は Ctrl+Z で戻せます。「塗りを消す」で手で塗った範囲を全部消します。塗った範囲はポーズと一緒に保存し、画像から取り出し直すと消えます。
- ポーズは編集画面の「保存」でカット案に保存されます。

### サムネイル一覧とビューワー
- カット案ごとに、生成した画像を一覧で見られます。プロンプトや Seed で検索・絞り込みができます。
- 画像はカット案をまたいで複数選択でき、まとめて削除できます。クリックで開き、Ctrl+クリックか右上の □ で 1 枚ずつ選ぶ・外す、Shift+クリックで範囲を選ぶ、ドラッグで囲んでまとめて選ぶ、ができます。
- プロンプト編集画面の上段のサムネイルも、サムネイル一覧と同じ大きさ・同じ操作です。選択も共通で、上段で選んだ画像はサムネイル一覧でも選ばれています。右の「すべて選択」「選択を解除」「再生成」「選択を削除」も一覧と同じです。左下にはコマで使っている印とお気に入りの ♥ が出ます。
- 「再生成」：選んだ画像を、元のプロンプト・Seed・サイズのまま Steps だけ変えて作り直すキューを登録します。
- ビューワーの「♡ お気に入り」（F キー）で、画像をお気に入りにできます。お気に入りの画像には、サムネイルとビューワーに ♥ の印が付きます。ビューワーでは、お気に入りとコマで使っている印を画像の左上に重ねて出します。サムネイル一覧とコマの画像選択では「♥ お気に入りのみ」で絞り込めます。
- ビューワーで S キー（「☐ 選択」）を押すと、その画像をサムネイル一覧の選択に加えます（もう一度で外します）。選んだ画像には左上に「✓ 選択中」と出るので、← → で見ながら選び、一覧に戻ってまとめて削除や再生成ができます。編集画面の上段から開いたときも同じ選択です。D キーでは表示中の画像を削除します（確認が出るので、Enter で削除、Esc でやめます）。
- プロジェクトの画面のカット案のカードには、左上にお気に入りの枚数（♥）と、Book のコマで使っている画像の枚数（コマの印）が出ます（0 枚なら出ません）。
- ビューワーでは、拡大縮小、キー画像（カードに出す画像）の指定、生成情報の表示、画像のプロンプトをカット案に戻す、img2img に送る、インペイントに送る、ができます。img2img・インペイントで生成した画像は、帯の「解除」を押すまで元のカット案に保存されます。
- ビューワーの「描き直す」で、ポラスタの中で img2img・インペイントができます（WebUI の画面には移りません）。
  - 画像の上をドラッグしてマスクを塗ります（Shift+ドラッグで消す、Alt+ホイールで筆の太さ）。マスクを塗れば塗ったところだけを描き直し（インペイント）、塗らなければ画像全体を描き直します（img2img）。
  - ノイズ除去強度（初期値 0.55）・マスクのぼかし・始め方（元の絵・塗りつぶし・ノイズ・空）・マスクのまわりだけ描き直す（余白）・枚数・Steps・Seed を選べます。プロンプトは元の画像の生成情報から始まり、「カット案から」で切り替えられます。カット案のポーズを使っているときは、ポーズ（ControlNet）も一緒に使えます。
  - できた画像はカット案に入り、右の一覧に「新」の印で並びます。押すとそれを元にして、続けて描き直せます（大きさが同じならマスクはそのまま）。設定は次に開いたときも残ります。
  - 生成は WebUI の img2img に頼みますが、元の画像とマスクはポラスタが渡すので、WebUI の img2img の画像欄やマスクは使いません。

### Book
- 「Book」は漫画のコマ割りのページ（コマページ）をまとめたものです。ドラッグで順番を決められます。
- コマ（四角）には、カット案を「このコマ用」として対応させておけます（任意）。画像の選択でカット案を開き、上の「📌 このコマに対応させる」を押します。対応させたコマには編集画面で左上にカット案の名前が出て（書き出しには入りません）、次から「画像を選ぶ」とそのカット案の画像から始まります。ほかのカット案の画像も「← カット案」から今までどおり選べます。
- コマページには名前を付けられます。Book の画面でコマページの下の欄（「名前を付ける」）を押すか、編集画面の上部バーの「ページの名前」に入力します。名前はコマで使っている印のページ名にも出ます（ZIP のファイル名は番号のままです）。
- プロジェクトの画面で **Alt+B** を押すと Book の画面を開き、Book の画面（コマページの編集中も）でもう一度 Alt+B を押すとプロジェクトの画面に戻ります。プロンプト編集の画面で押すと、編集画面を閉じて Book の画面を開きます（保存していない変更があれば確認が出ます）。
- 「コマページ作成」で、白紙のページ（初期値 1573 × 2200）を Book に足します。直線と四角を描き、四角を押すと画像の一部を切り出してはめ込めます。元の画像は変更しません。
- コマページの右上の「⧉」で、そのコマページを複製してすぐ後ろに足します。コマ割り・はめ込んだ画像・オノマトペなども同じになり、複製したほうを直しても元のページは変わりません。今のページを残したまま少し変えた版を作るときに使えます。
  - はめ込む画像は、カット案を選び、そのカット案のサムネイルから選びます。コマで使っている画像には印が付きます。
  - 「三角」でドラッグすると三角のコマを描けます。台形や平行四辺形は、四角（や三角）を選んで「頂点を編集」（E キー）を押し、角の丸いつまみをドラッグして作ります。
    - Shift を押しながらドラッグすると、角を元の位置から水平か垂直にだけ動かせます。矢印キーで、最後に触った角を 1 px（Shift で 10 px）ずつ動かせます。
    - 編集中は、その角の内角と、つながる 2 本の辺の傾き（水平・垂直からのずれ）を度で表示します。
    - 画像は形の外枠に合わせて置き、形で切り抜きます。「四角に戻す」で外枠の四角に戻せます。
  - 編集画面の「表示 1 枚・2 枚・3 枚」で、並べて表示するコマページの枚数を切り替えられます。右から Book の順に並び（漫画の見開きと同じ向き）、編集するのは「編集中」のページです。ほかのページはクリックすると編集できます。
  - 編集画面の上部バーの真ん中の「← プロジェクト「…」へ戻る」で、Book の画面を飛ばしてプロジェクトの画面に戻れます。
  - キャンバスの上のホイールを回す（または PageUp・PageDown）と、1 枚表示では前後のコマページに移り、2 枚以上では並びが 1 枚ずつずれます。ずらしたあとも、同じ位置（真ん中など）のページが編集中になります。
  - 吹き出し・集中線・小物などの画像は「素材」として置けます。エクスプローラーから画像ファイルをドロップするか、Ctrl+V でクリップボードの画像を貼り付けるか、「＋ 素材」で選びます。素材はコマと線の上に重なり（透明な所は下が見えます）、ドラッグで動かし、角のつまみで縦横比を保って大きさを変えられます。ページから一部はみ出させることもできます（はみ出した所は切れます）。
  - 「手描き線」（W キー）で、ドラッグした始点から終点まで、手で引いたように揺れる線を引けます（両端は筆の入り・抜きのように細くなります。Shift で水平・垂直）。太さ・揺れの大きさ・色・フチは下の行で選び、「🎲 別の揺れ」（G キー）で同じ設定のまま別の揺れ方にします。「細く」の「始め」「終わり」を外すと、その端は細くならず太さのままになります。「蛇行」を上げると、線の終わりのほうが蛇のようにくねります。「ここから」で線の何 % からくねらせるか、「波」で波の数を選び、くねりはそこから終点に向けてだんだん大きくなります。引いた線は「選択」で両端のつまみを動かせます。オノマトペと同じく素材の層に重なり、書き出しでは画面で描いた形の画像を使います。
  - セリフの道具はなくしました。セリフは、オノマトペの「≡ 整列」で置きます（下）。前の版で置いたセリフは、表示・移動・削除・書き出しだけできます。
  - 文字のフォントは、この PC に入っているフォントを使えます。書き出しでも同じフォントの字形のまま画像に入ります。
    - フォントは、見本付きの一覧から名前で検索して選びます。「追加したフォント」「★ お気に入り」「最近使った」で絞り込めます。
      - 一覧を開いたまま ↑↓ キーを押すと、フォントを順に試せます。選んでいるオノマトペにすぐ当たるので、見た目を比べながら選べます。Enter で決め、Esc で試す前のフォントに戻ります。試している間の切り替えは、元に戻す（Ctrl+Z）では 1 回分です。
      - 「追加したフォント」には、右クリック →「インストール」で入れたフォント（Windows の個人用のフォント）と `data/fonts/` のフォントが出ます。「すべてのユーザーに対してインストール」で入れたフォントは Windows に最初からあるフォントと見分けられないので、★ を付けて絞り込んでください。
      - ★ と最近使ったフォントはブラウザに覚えます。フォントを入れたあとは reForge を再起動すると一覧に出ます。
    - フォントを PC に入れずに使いたいときは、拡張フォルダの `data/fonts/` にフォントのファイルを置きます。
    - 複数のフェイスが入ったフォント（.ttc）の名前の表示と、編集画面での表示には `fontTools`（通常は WebUI に入っています）を使います。
  - 「オノマトペ」（O キー）で、効果音・擬音のパレットを右に開きます。登録した文字列と調整済みスタンプは、プロジェクトごとに別々です。
    - 「編集」で、使う文字列を 1 行に 1 つずつ登録します（テキストエディタからまとめて貼り付けられます）。登録した文字列はボタンになり、50 音順に並びます（同じ文字列は 1 つにまとまります）。
    - ボタンを押すとスタンプモードになります。ページを左クリックすると 1 つ置いてそのオノマトペを選んだ状態になり（すぐ調整できます）、右クリックすると置いたあともスタンプを続けて置けます。「置くたびに形を変える」がオンなら、置くたびに字の角度・大きさ・位置などが少しずつゆらぎ、同じ形になりません。文字列のスタンプは既定の形で置き、パレットではフォントと大きさを選びます（形は置いたあとの調整で変えます）。Esc か V で選択に戻ります。
    - 「選択」で置いたオノマトペを選ぶと、パレットが調整に変わります。文字・フォント・縦書き/横書き・大きさ・始めと終わりの大きさ・字間・傾き・斜体・曲がり・ゆらぎの幅・塗りとフチ（2 重まで）を変えられます。「🎲 別の形」（G キー）で、同じ設定のまま別のゆらぎにします。角のつまみで拡大・縮小できます。選んだオノマトペを Ctrl を押しながらドラッグすると、複製して置けます。
    - 調整の「🔤 フォント別の見え方」を押すと、パレットの左に枠がせり出し、今の形を ★ を付けたフォント・追加したフォント・最近使ったフォントで描いた見本が全部並びます（大きさや角度、字の手直しを変えるとすぐ反映されます）。もう一度押すか ✕ で閉じます。開いているかは覚えておき、オノマトペを選ぶたびに同じ状態で出ます。枠の 📌 で固定すると、オノマトペを選んでいないときも（空の）枠を出したままにし、ページの位置が動かなくなります。見本を押すとそのフォントになり、左上の「＋」でそのフォントの形を調整済みスタンプに登録できます。右上の ✕ で、好みでないフォントを一覧から外せます（コマページの編集画面を閉じると戻ります）。見本の並びは、フォントを選んでも変わりません。
    - 調整の「≡ 整列」をオンにすると、ゆらぎ・字のずれ・傾き・斜体・曲がり・始めと終わりの大きさを使わず、字を升目にそろえて並べます（セリフに使えます）。文字の欄で Enter を押すと改行になり（Ctrl+Enter で決める）、縦書きは右の行から左へ並びます。「行間」で行の間隔を変えられます。縦書きでは、「ー」や括弧を縦向きに回し、「、」「。」を右上に、小さい「っ」などを少し右上に寄せ、半角の数字・「!?」の 2 文字までを横に並べて 1 文字分に収めます（縦中横）。フチ・フキダシ・字の手直し・調整済みスタンプへの登録・書き出しは、ふつうのオノマトペと同じです。整列を外すと元の形に戻ります（改行はなくなります）。
      - パレットの「整列して縦書きで置く」をオンにすると、文字列のスタンプを、はじめから整列した縦書きで置きます。
    - ゆらぎの幅（字の角度・大きさ・全体の傾き・強さ）はオノマトペごとに持つので、「ドン」は大きく、「シーン」はほとんどゆらさない、のように決められます。
    - 「字のずれ」は、字を並びと直角の向きにずらします。「交互」では、隣り合う字がちょうどその割合（字の大きさに対する）ずれ、1 字目を右（横書きは上）にするか左（下）にするかを選べます。置くたびには変わりません。「ばらばら」では字ごとに乱数で決まり、置くたびに変わります（前の版で作ったオノマトペは「ばらばら」のままです）。
    - 「✥ 字を 1 つずつ直す」（E キー、または選んだオノマトペをダブルクリック）で、字を 1 つずつ選んで、ドラッグで動かす（Shift で縦か横だけ）、上の丸で回す（Shift で 15° ずつ）、右下の四角で大きさを変える、ができます。矢印キーで 1 px（Shift で 10 px）ずつ動かせ、パレットの数値でも直せます。ほかの字は動きません。外枠の角の色付きの四角をドラッグすると、字の手直しを続けたまま枠全体の大きさを変えられます。「この字を戻す」「すべての字を戻す」で元に戻せます。
    - 調整の「□ フキダシ」（B キー）で、オノマトペにフキダシ（白地に黒い線。はじめは四角）を付けられます。「頂点を編集」で頂点をドラッグで動かし、辺の真ん中の小さな丸をドラッグで頂点を足し（20 個まで）、頂点をダブルクリックで消せます。矢印キーで最後に触った頂点を動かせ、「四角に戻す」で四角に戻ります。🎲（頂点の編集中はフキダシの右上にも出ます）を押すたびに、外枠の大きさのままギザギザかゆがんだ多角形の形をランダムに作ります。「○ 丸く」（Shift+B）で丸いフキダシになります。頂点は角の目安になり、辺の真ん中を通るなめらかな線で囲みます（四角なら楕円、ギザギザなら雲や爆発のような形）。フキダシがなければ丸いフキダシを付けます。オノマトペを拡大・縮小するとフキダシも一緒に変わります。書き出しにも入ります。
    - 「＋ 調整済みに登録」で、調整した形をパレットの「調整済みスタンプ」に登録し、どのプロジェクトでも同じように置けます。調整済みスタンプも字の 50 音順に並び、下にフォント名が出ます。調整済みスタンプの置き方も、文字列のスタンプと同じです（左クリックで 1 つ置いて選ぶ、右クリックで続けて置く）。
    - オノマトペは素材と同じ層に重なります。書き出しでは、置いた大きさの 2 倍で描いた画像を使います（形を変えるたびに作り直し、素材と同じ所に保存します）。
- 「ZIP で書き出し」で、コマページを 1 枚ずつ PNG にし、Book 内の順番（`001.png`, `002.png` …）のファイル名で ZIP にまとめて保存します。生成情報などのメタ情報は入りません。

## データの保存場所

| 中身 | 場所 |
|---|---|
| プロジェクト（タグ定義・シーン・カット案・キュー・Book） | 拡張フォルダの `data/projects.json` |
| 生成した画像 | WebUI の出力フォルダの中の `polaris-studio/<プロジェクト>/<カット案>/`（初期設定では `outputs/polaris-studio/`） |
| コマページの素材の画像（オノマトペの書き出し用の画像も） | 同じく `polaris-studio/<プロジェクト>/.materials/`（メタ情報を持たない PNG） |
| オノマトペの文字列と調整済みスタンプ（プロジェクトごと） | 拡張フォルダの `data/sfx/<プロジェクトの id>.json` |

## 注意

- プロジェクトの削除は、プロジェクト一覧のタイルの「削除」からだけできます。確認画面で `DELETE` と入力したときだけ削除されます。
- Book の「Book を削除」も、確認画面で `DELETE` と入力したときだけ削除されます（中のコマページも一緒に消えます。はめ込んだ画像は残ります）。
- 画像やカット案、プロジェクトの削除は、画像の実ファイルごと削除します。ごみ箱が使える環境（Windows、または `send2trash` が入っている環境）では、画像はごみ箱に移るので、そこから戻せます。それ以外の環境では元に戻せません。
- `data/projects.json` は、保存のたびに `data/backups/` に控えを残します（10 分に 1 回、プロジェクト・カット案・Book が減る保存のときは毎回。新しいものから 30 件）。消してしまったプロジェクトを戻すときは、reForge を止めてから、戻したい時点の控えを `data/projects.json` に上書きコピーします。
- 保存するのは、その画面で変えたプロジェクトだけです。ブラウザを 2 つ（タブを 2 つ）開いて作業しても、片方の保存がもう片方で変えたほかのプロジェクトを上書きすることはありません（同じプロジェクトを両方で変えたときは、後から保存したほうが残ります）。
- オノマトペの `data/sfx/<プロジェクトの id>.json` も同じように `data/backups/sfx-<プロジェクトの id>-<日時>.json` に控えを残します（10 分に 1 回、文字列か調整済みスタンプが減る保存のときは毎回。新しいものから 30 件）。戻し方も同じです。プロジェクトを削除すると、そのパレットも消えます（控えは `sfx-<プロジェクトの id>-deleted-<日時>.json` に残ります）。
- 以前の版の、プロジェクトをまたいで共通だった `data/sfx.json` は、`data/sfx/` がまだないときに一度だけ、そのときあるプロジェクトそれぞれに写します（写したあとは `data/sfx.legacy-<時刻>.json` に名前を変えます）。新しく作ったプロジェクトのパレットは空から始まります。
- 「生成」・キュー・「再生成」は、カット案や元の画像のサイズを txt2img の幅・高さに書き込みます。実行後もその値が残ります。
