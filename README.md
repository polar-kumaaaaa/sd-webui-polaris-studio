# Polaris Studio（ポラスタ）

Stable Diffusion WebUI reForge 向けの拡張機能です。
画像生成を「プロジェクト → シーン → カット案」の単位で整理し、プロンプトの組み立て、試し生成、まとめての生成、できた画像の選別までを 1 つの画面で行えます。

*A reForge extension that organizes image generation into projects, scenes and cuts, with a tag-based prompt editor, generation queues, an image browser and "Books" exported as metadata-free ZIPs. The UI is in Japanese.*

## 動作環境

- [Stable Diffusion WebUI reForge](https://github.com/Panchovix/stable-diffusion-webui-reForge) で動作を確認しています。
- 追加のライブラリは不要です（WebUI に入っているものだけを使います）。

## インストール

1. WebUI の「Extensions」→「Install from URL」を開きます。
2. 「URL for extension's git repository」に次を入れて「Install」を押します。
   ```
   https://github.com/polar-kumaaaaa/sd-webui-polaris-studio.git
   ```
3. WebUI を再起動します。

画面上部の設定の行の右端に「Polaris Studio」ボタンが出ます。押すか **Alt+P** で開きます（もう一度 Alt+P で元の画面に戻ります）。

## 見本データ

`samples/projects.json` に、タグ定義・シーン・カット案の入った見本のプロジェクトがあります。
使うときは、WebUI を止めてから拡張フォルダの `data/projects.json` としてコピーし、起動し直してください。

```
extensions/sd-webui-polaris-studio/data/projects.json
```

> すでに `data/projects.json` があるときにコピーすると、今のプロジェクトがすべて置き換わります。
> 見本を読み込んだあとは、新しいプロジェクトを作るときに「タグ定義」で「サンプル からコピー」を選ぶと、見本のタグ定義を引き継げます。

## 主な機能

### プロジェクト・シーン・カット案
- プロジェクトごとに、シーンとカット案（1 枚の絵の案）を並べて管理します。カット案はドラッグで並べ替えられ、シーンをまたいで移動できます。
- シーンは折りたたんで 1 行にできます。
- 画像をシーンにドロップすると、その画像からカット案を作ります。

### プロンプト編集
- タグは「カテゴリ」ごとに登録します。カテゴリには「排他（1 つだけ）」「ネガティブ専用」を指定できます。
- 左のカテゴリから選んだタグを右に並べると、その順でプロンプトが組み立てられます。プロンプト欄は直接書き換えることもできます。
- 保存のたびに履歴を残し、前の状態に戻せます。

### 生成
- カット案ごとに画像のサイズ（幅 × 高さ）を持ちます。プロンプト編集の上部で変えられ、「⇄」で縦長と横長を入れ替えられます。同じプロンプトでも縦長と横長で絵の印象が変わるので、プレビューもキューもカット案のサイズで生成します。
  - サイズを決めていないカット案は、WebUI の幅・高さのまま生成し、最初に生成した画像のサイズを覚えます。
  - 新しいカット案は、同じシーンで最後にサイズを決めたカット案のサイズから始まります。画像をドロップして作ったカット案は、その画像のサイズになります。
- 「プレビュー」で 1 枚だけ試しに生成します。
- 「キュー」に Steps・Batch・Seed などを決めて登録し、キュー管理からまとめて実行します。
- 進捗は画面右上のトーストに出ます。生成中も画面は操作できます。
- 生成はいつもの txt2img の画面を使います。実行すると、プロンプト・Steps・Seed などが txt2img の欄に書き込まれます。

### サムネイル一覧とビューワー
- カット案ごとに、生成した画像を一覧で見られます。プロンプトや Seed で検索・絞り込みができます。
- 画像はカット案をまたいで複数選択でき、まとめて削除できます。
- 「再生成」：選んだ画像を、元のプロンプト・Seed・サイズのまま Steps だけ変えて作り直すキューを登録します。
- ビューワーの「♡ お気に入り」（F キー）で、画像をお気に入りにできます。お気に入りの画像には、サムネイルとビューワーに ♥ の印が付きます。サムネイル一覧とコマの画像選択では「♥ お気に入りのみ」で絞り込めます。
- ビューワーでは、拡大縮小、キー画像（カードに出す画像）の指定、生成情報の表示、画像のプロンプトをカット案に戻す、インペイントに送る、ができます。

### Book
- 「Book」は漫画のコマ割りのページ（コマページ）をまとめたものです。ドラッグで順番を決められます。
- 「コマページ作成」で、白紙のページ（初期値 1573 × 2200）を Book に足します。直線と四角を描き、四角を押すと画像の一部を切り出してはめ込めます。元の画像は変更しません。
  - はめ込む画像は、カット案を選び、そのカット案のサムネイルから選びます。コマで使っている画像には印が付きます。
  - 「三角」でドラッグすると三角のコマを描けます。台形や平行四辺形は、四角（や三角）を選んで「頂点を編集」（E キー）を押し、角の丸いつまみをドラッグして作ります。
    - Shift を押しながらドラッグすると、角を元の位置から水平か垂直にだけ動かせます。矢印キーで、最後に触った角を 1 px（Shift で 10 px）ずつ動かせます。
    - 編集中は、その角の内角と、つながる 2 本の辺の傾き（水平・垂直からのずれ）を度で表示します。
    - 画像は形の外枠に合わせて置き、形で切り抜きます。「四角に戻す」で外枠の四角に戻せます。
  - 編集画面の「表示 1 枚・2 枚・3 枚」で、並べて表示するコマページの枚数を切り替えられます。右から Book の順に並び（漫画の見開きと同じ向き）、編集するのは「編集中」のページです。ほかのページはクリックすると編集できます。
  - 編集画面の上部バーの真ん中の「← プロジェクト「…」へ戻る」で、Book の画面を飛ばしてプロジェクトの画面に戻れます。
  - キャンバスの上のホイールを回す（または PageUp・PageDown）と、1 枚表示では前後のコマページに移り、2 枚以上では並びが 1 枚ずつずれます。ずらしたあとも、同じ位置（真ん中など）のページが編集中になります。
  - 吹き出し・集中線・小物などの画像は「素材」として置けます。エクスプローラーから画像ファイルをドロップするか、Ctrl+V でクリップボードの画像を貼り付けるか、「＋ 素材」で選びます。素材はコマと線の上に重なり（透明な所は下が見えます）、ドラッグで動かし、角のつまみで縦横比を保って大きさを変えられます。ページから一部はみ出させることもできます（はみ出した所は切れます）。
  - 「セリフ」（T キー）でクリックした所に文字を置けます。フォント（この PC に入っているフォント）、大きさ、縦書き・横書き、行間、字間、色、フチを選べます。書き出しでも同じフォントの字形のまま画像に入ります。
    - 縦書きでは、「ー」や括弧を縦向きに回し、「、」「。」を右上に寄せ、半角の数字・「!?」の 2 文字までを横に並べて 1 文字分に収めます（縦中横）。
    - フォントは、見本付きの一覧から名前で検索して選びます。「追加したフォント」「★ お気に入り」「最近使った」で絞り込めます。
      - 「追加したフォント」には、右クリック →「インストール」で入れたフォント（Windows の個人用のフォント）と `data/fonts/` のフォントが出ます。「すべてのユーザーに対してインストール」で入れたフォントは Windows に最初からあるフォントと見分けられないので、★ を付けて絞り込んでください。
      - ★ と最近使ったフォントはブラウザに覚えます。フォントを入れたあとは reForge を再起動すると一覧に出ます。
    - フォントを PC に入れずに使いたいときは、拡張フォルダの `data/fonts/` にフォントのファイルを置きます。
    - 複数のフェイスが入ったフォント（.ttc）の名前の表示と、編集画面での表示には `fontTools`（通常は WebUI に入っています）を使います。
- 「ZIP で書き出し」で、コマページを 1 枚ずつ PNG にし、Book 内の順番（`001.png`, `002.png` …）のファイル名で ZIP にまとめて保存します。生成情報などのメタ情報は入りません。

## データの保存場所

| 中身 | 場所 |
|---|---|
| プロジェクト（タグ定義・シーン・カット案・キュー・Book） | 拡張フォルダの `data/projects.json` |
| 生成した画像 | WebUI の出力フォルダの中の `polaris-studio/<プロジェクト>/<カット案>/`（初期設定では `outputs/polaris-studio/`） |
| コマページの素材の画像 | 同じく `polaris-studio/<プロジェクト>/.materials/`（メタ情報を持たない PNG） |

## 注意

- プロジェクトの削除は、プロジェクト一覧のタイルの「削除」からだけできます。確認画面で `DELETE` と入力したときだけ削除されます。
- 画像やカット案、プロジェクトの削除は、画像の実ファイルごと削除します。ごみ箱が使える環境（Windows、または `send2trash` が入っている環境）では、画像はごみ箱に移るので、そこから戻せます。それ以外の環境では元に戻せません。
- `data/projects.json` は、保存のたびに `data/backups/` に控えを残します（10 分に 1 回、プロジェクト・カット案・Book が減る保存のときは毎回。新しいものから 30 件）。消してしまったプロジェクトを戻すときは、reForge を止めてから、戻したい時点の控えを `data/projects.json` に上書きコピーします。
- プレビュー・キュー・「再生成」は、カット案や元の画像のサイズを txt2img の幅・高さに書き込みます。実行後もその値が残ります。
